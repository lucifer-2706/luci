# Text2Cinematic

A professional browser-based app that converts text into high-quality animated video clips.

## Features
- Cinematic 1280x720 canvas output
- Multiple themes and typography presets
- Adjustable duration and FPS controls
- Real-time preview
- One-click WebM export using VP9 encoding

## Run locally
```bash
python3 -m http.server 4173
```
Then open `http://localhost:4173`.
